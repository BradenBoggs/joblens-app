# Brand artwork

`icon.png` is the existing JobLens orange square mark, reused without redrawing or changing its proportions. It is used in the app header, splash configuration, and initial app icon.

This is the original 2000 × 2000 PNG with transparent edge pixels. Inspect Expo-generated native launcher assets on both platforms before release; store-ready icon exports and signing are part of native release preparation, not proof supplied by a JavaScript bundle check.
